# TsundereGram API (Cloudflare Worker)

Сервер, через который приложение работает со значками, баннерами, рамками и цветами профиля.
**Токен бота хранится только здесь** — в APK его больше нет.

**Текущий адрес:** https://tsundere-api.tsunderegram.workers.dev — прописан в переменной репозитория `TSUNDERE_API_URL` и вшивается в APK при сборке.

## Что умеет

| Запрос | Кто может |
|---|---|
| `GET /bot/getChat` — прочитать конфиг (закреп в канале) | все, кэш 15 с |
| `GET /bot/getFile`, `GET /file/<path>` — файлы значков/баннеров | все, кэш сутки |
| `POST /bot/sendDocument` — загрузить картинку/видео в канал | вошедшие через Telegram |
| `POST /bot/editMessageText` — сохранить конфиг | вошедшие через Telegram, по правилам ниже |
| `GET /info` — имя бота, `GET /setup` — кнопка мини-приложения | все |

Любые другие методы Bot API запрещены, `chat_id` всегда подменяется на канал конфига.

**Как сервер узнаёт пользователя.** Приложение просит у Telegram открыть мини-приложение бота
(`messages.requestSimpleWebView`) и получает `initData` — данные пользователя, подписанные
Telegram токеном бота. Сервер проверяет подпись (HMAC-SHA256), поэтому подделать чужой `user id`
нельзя. Подпись действует сутки, приложение обновляет её само; никаких окон пользователь не видит.

**Правила записи конфига** (сервер берёт старый конфиг и переносит из нового только разрешённое):
- обычный пользователь — только свои записи: баннер, рамка, цвета профиля, градиент ника,
  отметка «пользуется TsundereGram»;
- баннер канала (ключ `-100…`) — тот, кто поставил его первым, дальше только он (или админ);
- значки — только админы значков (`admins` в конфиге) и создатель;
- список админов — только создатель (`CREATOR_IDS`) и только запросом с флагом `admins_change`
  (кнопки «Сделать админом» / «Отозвать права»), чтобы старая копия конфига не возвращала отозванных.

## Установка (5 минут, бесплатно)

1. **Новый токен.** Старый лежал в старых APK и в истории репозитория — его надо отозвать:
   @BotFather → `/mybots` → бот → *API Token* → *Revoke current token*. Скопируйте новый.
   Бот должен оставаться админом канала `@TsundereGram_Banners` с правом редактировать сообщения.
2. **Worker.** https://dash.cloudflare.com → *Workers & Pages* → *Create* → *Create Worker* →
   имя `tsundere-api` → *Deploy* → *Edit code* → вставьте весь `worker.js` → *Deploy*.
3. **Секрет.** Worker → *Settings* → *Variables and Secrets* → *Add* → тип **Secret**,
   имя `BOT_TOKEN`, значение — новый токен → *Deploy*.
   (Необязательно: переменные `CHANNEL` и `CREATOR_IDS`, по умолчанию `@TsundereGram_Banners` и `5133421262`.)
4. **Проверка.** Откройте `https://tsundere-api.<ваш-поддомен>.workers.dev/info` — должно быть
   `{"ok":true,"bot":"имя_бота",...}`. Затем один раз откройте `/setup` (ставит боту кнопку
   мини-приложения — запасной способ авторизации).
5. **Приложение.**
   - Сразу: профиль любого пользователя → «Выдать значок» → иконка 🔗 (видна только создателю) →
     вставьте адрес Worker → «Сохранить».
   - Для всех пользователей: GitHub → репозиторий → *Settings* → *Secrets and variables* →
     *Actions* → *Variables* → *New repository variable* `TSUNDERE_API_URL` =
     `https://tsundere-api.<ваш-поддомен>.workers.dev`. Следующие сборки вшивают адрес в APK.

Через CLI вместо дашборда: `npx wrangler deploy` и `npx wrangler secret put BOT_TOKEN` в этой папке.

Лимиты бесплатного Cloudflare: 100 000 запросов в сутки — с кэшем хватит с большим запасом.

## Распознавание голосовых (POST /transcribe)

Worker умеет расшифровывать голосовые и кружки через Workers AI (`@cf/openai/whisper-large-v3-turbo`),
поэтому в приложении распознавание работает «из коробки», без своих ключей Cloudflare.

- Нужна привязка Workers AI: *Worker → Settings → Bindings → Add binding → Workers AI*, имя `AI`
  (в `wrangler.toml` она уже описана секцией `[ai]`).
- Запрос авторизуется так же, как остальные (initData мини-приложения), аудио — base64 до ~30 МБ.
- Бесплатный лимит Workers AI — 10 000 «нейронов» в сутки; при превышении приложение покажет понятную ошибку.
